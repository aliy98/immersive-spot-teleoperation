Citing
======

If you use this software or the methods it implements, please cite the
accompanying paper:

    A. Yousefi, C. T. Recchiuto, and A. Sgorbissa,
    *Design and User Evaluation of an Immersive Teleoperation System
    for a Quadruped Robot*.

Code: https://github.com/aliy98/immersive-spot-teleoperation

The user study (:math:`N = 30`) compared this stack with the stock Spot
tablet after matching field of view. Objective metrics were completion
time and features identified per minute; subjective instruments were
the Presence Questionnaire and the Simulator Sickness Questionnaire.
Those results live in the paper, not in this repository.
